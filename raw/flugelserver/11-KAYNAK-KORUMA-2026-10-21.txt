1. Resource protection
- /usr/local/sbin/kaynak-gozcu.sh runs every 2 minutes via kaynak-gozcu.timer. It checks memory pressure, swap, memory PSI, VMs, GPU temperature, and recent OOM events; it notifies on new state changes.
- /usr/local/sbin/ai-vm-koruma.sh runs every 10 seconds via ai-vm-koruma.timer. The libvirt qemu hook also calls it before a VM reserves host RAM.
- When any VM starts or is running, these AI containers are stopped: open-webui, lingarr, immich_machine_learning, subgen, ollama. The flugel-akis container stays up so feed collection continues; translation and scoring wait until Ollama returns.
- AI containers also stop if all VMs are off but MemAvailable falls below 2500 MB. They resume only when all VMs are off and MemAvailable is at least 4000 MB. Only containers stopped by the guard are restarted.
- For GPU passthrough, the qemu hook also stops GPU containers plex, immich_server, beszel-agent, stirling-pdf, and convertx, then restarts them after VM shutdown.
- Backups before changes: /usr/local/sbin/ai-vm-koruma.sh.before-ramguard, /etc/libvirt/hooks/qemu.before-ai-vm-pause, and qemu.before-gpu-container-audit.
